# 🛍️ Online Sales Coupon Analysis

This project explores real-world retail data to uncover insights on how customers use **discount coupons** across different **demographics, campaigns, and products**.

The dataset is cleaned and transformed using **Python (pandas, seaborn, matplotlib)**, with the goal of preparing it for visualization in **Power BI**.

---

## 🎯 Objectives

- Analyze coupon usage by customer **demographics** (age, income, family size, etc.)
- Identify trends across **campaigns**, **products**, and **brands**
- Summarize **discount behavior** for business insights
- Prepare a clean dataset for visualization dashboards

---

## 📊 Tools & Technologies Used

- **Python**: Data Cleaning, Merging, and Transformation  
- **pandas**, **matplotlib**, **seaborn**: Exploratory Data Analysis  
- **Power BI** *(next phase)*: Dashboard-ready dataset creation

---

## 📁 Dataset Information

Sourced from **Kaggle**: [Predicting Coupon Redemption](https://www.kaggle.com/competitions/predicting-coupon-redemption)

**Files Used:**
- `customer_transaction_data.csv`
- `customer_demographics.csv`
- `coupon_item_mapping.csv`
- `campaign_data.csv`

## 📌 Key Insights

- 📌 **Married users** showed significantly higher coupon usage  
- 📌 **Lower income** customers are more responsive to discounts  
- 📌 **Family size** of 3–4 members leads to highest coupon redemption  
- 📌 **Younger users** (25–40 age group) dominate coupon redemption patterns  
- 📌 Coupon type also affects redemption rate significantly
